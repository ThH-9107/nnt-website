# Content Architecture — Portfolio

## 1. Primary principle

The portfolio is not organized as a list of résumé categories.

The main conceptual navigation is based on **scales of attention**:

1. **IMAGE**
2. **ORGANISM**
3. **LEARNER**
4. **COMMUNITY**
5. **AUDIENCE**

Secondary action verbs:
- IMAGE — *See*
- ORGANISM — *Test*
- LEARNER — *Share*
- COMMUNITY — *Serve*
- AUDIENCE — *Express*

The primary labels should be the **scale names**, not the verbs.

## 4. Project-story architecture

Normal homepage browsing should open project stories as large editorial overlays / route-aware drawers.

The scale map remains conceptually present.

Project overlays:
- nearly full-screen
- clear "Back to Inquiry Map"
- scale label / position
- optional next / previous scale
- close restores exact prior map state

Direct URLs must remain available.

The same content component should be reusable for:
- overlay presentation
- standalone direct route

Avoid duplicating factual copy across two implementations.

## 5. Distinct narrative mechanics by project

### Medical AI
Mechanic: **evolution of the research question**

Suggested structure:
1. why the question started
2. 2023 prototype
3. 2024 inconclusive augmentation work
4. move to medical imaging
5. self-supervised learning
6. current method
7. experiment scale
8. current result + trade-off
9. manuscript
10. what remains uncertain

Visual language:
- grid
- image / representation
- controlled comparisons
- research-path branching

### Phytophthora
Mechanic: **field → lab → revise**

Suggested sequence:
FARM → SYMPTOM → SAMPLE → CULTURE → OBSERVE → REVISE

Include experimental loop:
sample → isolate → inspect → inconsistent → revise ↺

Do not manufacture a final result.

### MoleBio
Mechanic: **before / after + one learner → group**

Before:
- ~16-member predecessor
- lecture / self-study-heavy

After:
- 20-member hands-on MoleBio
- 36 sessions
- ~48h
- lab skills
- workshops
- outreach

Photo-heavy.

### Hoa Yen
Mechanic: **one initiative → recurring organization**

Suggested:
origin → 2024 programs → 2025 rural expansion → 2026 larger programs

Use:
- program timeline
- light geographic logic
- real photography
- documented impact

Do not turn into a KPI dashboard.

### Creative
Mechanic: **production archive / audience**

Use:
- large photos
- production titles
- role
- collaboration
- selected reflection

Do not force research metrics into the page.

## 7. Fast-path behavior

A busy admissions reader should be able to reach:
- Medical AI
- résumé
- Hoa Yen
- basic About

within seconds.

The concept must reward exploration without requiring exploration.

## 8. Deep-content rule

The website should add what the résumé cannot show:
- chronology
- decisions
- uncertainty
- personal contribution
- photos
- diagrams
- failed / inconclusive work
- reflections
- evidence
- process

Avoid copying résumé bullets verbatim into long pages.
